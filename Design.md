# Design (from Figma screenshots)

## Colors
| Token | Value | Use |
|---|---|---|
| `--red` | `#DB4444` | Primary buttons, sale tags, accents |
| `--red-dark` | `#C53B3B` | Button hover |
| `--black` | `#000000` | Top bar, footer, add-to-cart bar, text |
| `--grey` | `#F5F5F5` | Search, card image background |
| `--muted` | `#7D8184` | Secondary text, old price |
| `--green` | `#00FF66` | "Buy Now" and NEW tag |
| `--star` | `#FFAD33` | Rating stars |

## Typography
Poppins (400, 500, 600, 700 for logo/countdown). Logo 24px/700 with letter-spacing .04em · Section title 36px/600 · Hero 48px/600 · Body 16px · Small 12–14px.

## Components
- Buttons: radius 4px, padding 16px 48px, red filled / black-border outline.
- Cards: grey image area (270×250 ratio), black "Add To Cart" bar on hover, red `-%` tag, heart + eye round buttons.
- Section label: 20×40 red block + red text, title below.
- Inputs: auth = underline only; contact/cart = bordered 4px radius; subscribe = white border on black.
- Footer: black, 5 columns (Exclusive/Subscribe, Support, Account, Quick Link, Download App).

## Layout
Container 1170px max; sections spaced 140px; breakpoints 1024 / 768 / 480.
